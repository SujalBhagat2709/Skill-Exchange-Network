# Skill Exchange Network

## Overview

Skill Exchange Network connects people who want to learn skills with people who can teach those skills.

The system also looks for reciprocal exchanges, allowing two people to help each other instead of simply finding a one-way teacher.

## Example

Person A:

Offers:
- Python
- Excel

Wants:
- JavaScript
- Web Development

Person B:

Offers:
- JavaScript
- Web Development

Wants:
- Python
- Excel

The system identifies a mutual skill exchange.

## Features

- Add Members
- Skills Offered
- Skills Wanted
- Availability Matching
- Skill Match Scoring
- Best Match Recommendation
- Mutual Exchange Detection
- Network Listing
